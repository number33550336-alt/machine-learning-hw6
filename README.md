# APS Failure Prediction

This project predicts air pressure system failures from sensor data.

- Prepare and explore the APS Failure dataset, including its missing values and class imbalance.
- Compare random forest and XGBoost models, and examine class weighting and SMOTE.
- Evaluate the models on the provided test set.

# APS 故障预测

本项目使用传感器数据预测空气压力系统故障。

- 整理并探索 APS Failure 数据集，包括缺失值和类别不平衡问题。
- 比较随机森林和 XGBoost，并尝试类别权重与 SMOTE。
- 使用数据集提供的测试集评估模型。
